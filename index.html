How this works

The database holds Division C Disease Detectives tests from the 2023 to 2026 Test Exchange lists, broken into question groups. Each group records the problem number, a short label of what it asks, the question type, and a link to the test file.

It does not store the question wording. Uploading a picture runs a small reading model in your browser to get the text, then matches it; pasting text matches its words directly against the type labels and how-to text, so the match is by topic. Use the filters to be exact: pick a type, a format, a method keyword, or a tournament.

Problem numbers are shown as written on each test. Where a test restarts its numbering or has none, a section prefix or order of appearance was used, so check the test. Tests without a printed date are marked approximate and sort by year.

Your practiced marks are stored in this browser only.
